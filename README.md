# Codex Agent Starter

A minimal starter project for working with Codex agents.

## What this includes

- `AGENTS.md` with practical defaults for coding workflows
- `.gitignore` for common local artifacts

## Quick start

1. Open this folder in Codex.
2. Ask Codex to read `AGENTS.md` and follow project instructions.
3. Customize the rules for your team and stack.
